## 各实验说明

### 实验一：E-R 概念模型与逻辑结构设计

- **题目**：为学校教务系统建模。学校下设若干**系**，每个系有若干**班级**和**教研室**；教研室有若干**教员**；学生分为本科生和研究生；正/副教授可指导若干研究生；班级包含若干学生；学生与课程之间为多对多**选修**关系（含成绩属性）。
- **画图工具**：[draw.io](https://app.diagrams.net/)，采用 Chen 表示法（矩形实体 + 椭圆属性 + 菱形联系 + ISA 三角）。
- **关键设计**：引入 ISA 特殊化 —— 教员派生出「普通教员」与「(正/副)教授」，学生派生出「本科生」与「研究生」，并将「指导」联系仅连在两个子类之间，从而精确表达「只有正/副教授才能带研究生」的约束。
- **逻辑结构**：1:n 联系并入 n 端作外码；m:n 联系（选修）单独建表并取联合主键；子类继承父类主键作主码兼外码。完整关系模式与建表 SQL 见 `lab1/数据库逻辑结构设计.md`，其中「导师必须为教授」的约束以触发器 `trg_AdvisorMustBeProfessor` 实现。

### 实验二：MySQL Workbench 建库建表与完整性测试

- **环境**：Windows 10 / MySQL 8.0 Community Server / MySQL Workbench 8.0，全程图形化操作，不写 SQL。数据库名 `test2`。
- **数据表**：
  - `Student`(`Sno` CHAR(10) 主键, `Sname` VARCHAR(50) 非空, `Ssex` ENUM('男','女') 默认'男', `Sage` INT, `Sdept` VARCHAR(50))
  - `Course`(`Cno` CHAR(10) 主键, `Cname`, `Credit`, `Cteacher`)
  - `SC`(`Sno`, `Cno`, `Grade`)，(`Sno`, `Cno`) 联合主键，两个外键级联 `ON DELETE/UPDATE CASCADE`
- **注意**：建库时显式指定 `utf8mb4` / `utf8mb4_general_ci`，表引擎统一 InnoDB，否则中文乱码或外键 errno 150。
- **完整性测试**（故意录入非法数据观察报错）：
  - 实体完整性 → `Error 1062` 主码重复/为空
  - 参照完整性 → `Error 1452` 外码在被参照表中无对应主码（另 `1451` 表示主表记录正被引用）
  - 用户定义完整性 → `Error 1265` 列取值非法（ENUM 越界）
